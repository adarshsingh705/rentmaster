## Decisions

| # | Section | Decision | Rationale | Date |
|---|---|---|---|---|
| D-1 | Architecture | NestJS (not raw Express) as backend framework | User explicitly specified "NestJS + Express"; NestJS provides built-in DI, module system, Guards for JWT, interceptors — superior for a secure multi-tenant API | 2026-06-11 |
| D-2 | Auth | JWT (Access + Refresh token pair) via Supabase Auth + NestJS Guard | Supabase issues the JWT; NestJS JwtGuard validates on every protected route. Stateless, scalable, no session store needed | 2026-06-11 |
| D-3 | Payment Gateway | Cashfree (Phase 1 only) via PaymentService abstraction | User confirmed Cashfree as active gateway; DB schema and PaymentService interface are gateway-agnostic to allow future swap | 2026-06-11 |
| D-4 | Scheduler | BullMQ + Upstash Redis (not node-cron) | Persistent job queue — survives server restarts. Critical for rent reminders which must never be lost | 2026-06-11 |
| D-5 | Multi-tenancy | Shared DB + Supabase RLS + NestJS TenantGuard | Database-enforced isolation; NestJS guard injects owner_id into every request for secondary application-level check | 2026-06-11 |
| D-6 | Scope | Phase 1 only — Cashfree auto-payment link + BullMQ reminder engine + NestJS API | Phase 0 (UPI manual) already validated. Phase 1 adds full automation. Phase 2+ (mobile app, analytics) deferred | 2026-06-11 |
| D-7 | WhatsApp | Interakt BSP (not direct Meta API) | Cheapest India BSP (₹999/month), approved templates UI, reliable delivery | 2026-06-11 |
| D-8 | Frontend | Next.js 14 App Router + shadcn/ui | Unified codebase, SSR for SEO, Supabase auth integration native | 2026-06-11 |
| D-9 | Auth | Email + Password login only in Phase 1; OTP/phone login deferred | User explicitly stated OTP is not part of Phase 1 — will be added as an additional auth method in a future phase | 2026-06-11 |
| D-10 | Scope | Phase 1 includes full bank account onboarding UI (not backend-only) | User confirmed full end-to-end UI for bank account entry, penny-drop status, and re-submission | 2026-06-11 |
| D-11 | Scope | Phase 1 is the complete fully-automated rent collection system | User confirmed: bank onboarding → Cashfree payment link → BullMQ reminder engine → webhook auto-mark-paid → Supabase Realtime dashboard, all in Phase 1 | 2026-06-11 |
| D-12 | Auth | Google OAuth ("Sign in with Google") added to Phase 1 alongside email+password | User explicitly requested Google login. Supabase Auth supports Google OAuth natively — no extra infrastructure. Apple and other social providers deferred. | 2026-06-11 |
| D-13 | Security | Every bank account submission requires email OTP (FR-10A) — no exception for first-time registration | User confirmed OTP always required as the safer default. Prevents unauthorised payout redirection regardless of account state. Email OTP only; phone OTP for login remains deferred. | 2026-06-11 |
